# CCANsolutions Collaborative Website
CMIS 4920 Capstone Project

---

## 1. Project Overview

This project is a collaborative website developed as part of the CMIS 4920 Capstone course. The purpose of this application is to demonstrate team-based software development using GitHub, agile sprint practices, and modern web technologies.

The system focuses on structured collaboration, documentation, and version control while delivering a functional and maintainable website.

---

## 2. Setup & Installation

### Dependencies
- Web Browser (Chrome, Firefox, Edge)
- GitHub Account

Currently, no environment variables are required.

To run locally:
1. Clone the repository

## 4. Development Workflow

This project follows a structured branching strategy:

- **main**  
  Stable production-ready code only

- **develop**  
  Main integration branch for all features

- **feature/***  
  Individual feature branches (example: `feature/readme-update`)

### Workflow
1. Create feature branch
2. Make changes
3. Submit pull request to develop
4. Peer review
5. Merge after approval
